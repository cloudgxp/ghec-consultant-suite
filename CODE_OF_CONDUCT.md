# Code of Conduct

We want everyone contributing to or using the **GHEC Consultant Suite** to feel welcome, respected, and safe. This Code of Conduct applies to all issues, pull requests, code reviews, discussions, and team channels related to this project.

---

## How we treat each other

By default, we expect all maintainers, migration consultants, and contributors to treat each other with kindness and respect.

To help keep our community welcoming, please:

- Use friendly, welcoming language and write clearly so everyone can understand.
- Be patient with new contributors and people asking questions about complex GitHub migrations.
- Give helpful, polite feedback during code reviews—focus on improving the code, not criticizing the person.
- Respect different viewpoints, backgrounds, and levels of experience.
- Accept constructive feedback graciously when someone spots a bug or suggests a simpler way to do something.

---

## Behavior we do not allow

To keep our project safe for everyone, the following behaviors are never allowed:

- Insults, put-downs, personal attacks, or mocking someone's questions or code.
- Harassment, intimidation, or unwelcome personal attention in public or private messages.
- Sharing someone else's private information—or sharing private customer GitHub tokens, repository names, or migration data—without permission.
- Trolling, derailing discussions, or pushing others to break security rules.

---

## Reporting a problem

If you experience or see behavior that goes against this Code of Conduct, please let the project maintainers know right away so we can help.

To report a Code of Conduct issue privately:

1. Contact the core maintainers listed in [`COLLABORATORS.md`](COLLABORATORS.md) or open a private report through GitHub.
2. Share links to the issue, pull request, or comment where the problem happened.
3. All reports are reviewed privately, and we will never share your name without your permission.

---

## How we handle violations

When a maintainer receives a report, we review what happened and take fair action to protect the community:

1. **First or minor mistake:** A private warning explaining what went wrong and how to fix it.
2. **Repeated or rude behavior:** Temporary removal from issues, pull requests, and project discussions.
3. **Severe harassment or data leaks:** Permanent ban from the repository and organization.

> [!NOTE]
> This Code of Conduct is adapted from the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html), rewritten in plain English to match our project documentation style.
