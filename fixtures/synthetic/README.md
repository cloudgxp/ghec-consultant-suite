# Fictional discovery bundles

`enterprise-v1.json` contains two fictional organizations, a partial enterprise enumeration, unknown LFS metrics, a failed security collector, and an advisory finding. `organization-v1.json` shows the same contract for one fictional organization. All names, timestamps, counts, IDs, and outcomes are invented; no API response or customer data was used.

Run `npm run validate:fixtures`. These fixtures exercise the contract, not live collectors or permission guarantees. Secret **names** are fictional metadata; there are no secret values. Coverage observed/expected counts represent enumerated target resources, not entity counts. The dashboard importer is deferred.
