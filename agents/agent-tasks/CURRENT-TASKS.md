## Status Vocabulary

- **Open**: Work has not started or a required deliverable is absent.
- **In progress**: Implementation exists, but required work remains.
- **Verification needed**: Implementation appears present, but acceptance evidence is missing or a required quality gate is not green.
- **Blocked**: Completion requires an external decision, credentialed environment, or other dependency.
- **Complete**: Acceptance criteria are met, quality gates pass (`npm run check`), and task is moved to `completed/`.
- **Superseded**: A later task replaced the approach. The replacement task and its evidence must be named.
