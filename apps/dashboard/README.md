# @ghec/dashboard — Offline Migration Assessment & Control Plane

The `@ghec/dashboard` application is a local, air-gapped Vite + React 19 + GitHub Primer application designed for consultants assessing GitHub Enterprise Cloud (GHEC) migration readiness and posture.

---

## Key Capabilities

1. **Air-Gapped & Zero-Credential Architecture:**
   - Operates 100% offline in the consultant's local browser without connecting to GitHub or external servers.
   - Evaluates discovery bundle files (`.json`) completely client-side with zero local secret or token exposure.
2. **Deterministic Readiness Scoring:**
   - Integrates `@ghec/analysis` to automatically calculate migration complexity, risk flags, and blocker classifications.
   - Identifies oversized repositories (>40 GiB), large commits (>2 GiB), Git LFS asset dependencies, and release boundary limits (>10 GiB).
3. **Multi-Organization & Inventory Analytics:**
   - Virtualized data tables powered by `@tanstack/react-virtual` capable of handling tens of thousands of repositories, teams, users, and secrets without performance degradation.
   - Granular search, filtering by module, and side-by-side scan comparisons.
4. **Client-Side Export & Deliverables:**
   - Generates professional client-ready PDF assessment deliverables via `jspdf` and `jspdf-autotable`.
   - Exports raw inventory and readiness metrics to CSV for executive reporting.

---

## Quick Start

From repository root:

```bash
# Launch development server on 127.0.0.1:5173
npm run dev

# Or directly in dashboard workspace
npm run dev -w @ghec/dashboard
```

Navigate to `http://localhost:5173` and upload any discovery bundle JSON file generated by `ghec-consultant-cli discover` or synthetic fixtures from `fixtures/synthetic/`.
