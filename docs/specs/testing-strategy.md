# Testing strategy

The default suite requires no credentials or GitHub network access. Current tests cover schema/fixture semantics and offline command behavior; the remainder are release requirements, not implemented test suites.

| ID / layer                           | Cases and acceptance criteria                                                                                                                                                         | Current coverage                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| TEST-UNIT-001 / parser               | Exclusive scope, explicit modules, dependencies, duplicates, malformed list, unsupported options/formats; no values echoed                                                            | Implemented                                                                          |
| TEST-CONTRACT-001 / schema           | Organization/enterprise fixtures; missing fields, forbidden secret property, invalid unknown metric, version rejection, bad references, cross-org links, inconsistent summaries/times | Implemented                                                                          |
| TEST-FIXTURE-001 / synthetic         | All fixture provenance fictional, stable deterministic content, no real customer resources; validate via script                                                                       | Implemented validation; human review required for every fixture change               |
| TEST-CLI-001 / command               | Help/version, valid invocation, all options/defaults, no credential output, no writes, correct exit status                                                                            | Core scaffold smoke tests implemented; live command cases deferred                   |
| TEST-API-001 / mocked adapter        | Multiple pages, empty pages, repeated cursors, transient errors, denied/hidden resources, partial GraphQL errors, primary/secondary throttles, abort and retry caps                   | Deferred with adapter                                                                |
| TEST-COL-001 / collectors            | Every module with full/partial/failed/unavailable input; anchor failures; org isolation; allowlisted metadata only                                                                    | Deferred; registry completeness checked now                                          |
| TEST-INTEGRATION-001 / orchestration | Approved operation registry, no mutations, no raw payload leakage, atomic output/collision/cancellation, continuation semantics                                                       | Deferred                                                                             |
| TEST-ANALYSIS-001 / rules            | Determinism, evidence traceability, unknown prerequisites, approved thresholds, org aggregation and no false reassurance                                                              | Deferred; no rules implemented                                                       |
| TEST-UI-001 / dashboard              | Import errors/version states, filters/sort/drill-down, memory reset, oversize/cancellation and no network/storage                                                                     | Deferred                                                                             |
| TEST-A11Y-001 / accessibility        | Automated checks plus keyboard/screen reader, contrast, noncolor states, 200% zoom, mobile layout; every implemented user workflow                                                    | Deferred; shell not a claim of full conformance                                      |
| TEST-EXPORT-001 / reports            | CSV formula/control-char injection, Unicode/newlines, exact filtered scope; jsPDF page breaks/long tables/fonts/coverage captions and offline generation                              | Deferred                                                                             |
| TEST-COMPAT-001 / version matrix     | Every supported producer schema against every supported reader; old compatible normalization and future/incompatible rejection                                                        | v1 validation/rejection implemented; cross-release fixtures deferred                 |
| TEST-SEC-001 / secret sentinels      | Prohibited values embedded in names/errors/headers/payloads; all logs/files checked; opt-ins cannot bypass policy                                                                     | Parser diagnostic and strict-property cases now; collector/output redaction deferred |
| TEST-E2E-001 / approved live         | Synthetic organizations only, verified least privilege and roles, read-only transport audit; collect → import offline → export                                                        | Deferred and explicitly authorized separately                                        |

Run `npm run check` for lint/format, source typechecking, full builds and current tests. `npm run validate:fixtures` checks both full fixtures. Tests use Node test runner with tsx. They must not use customer data or require secrets. Test sentinels are deliberately fictional strings, never real tokens.

**TEST-GATE-001.** Keep live tests opt-in and separate; record source/API version/date for live capability verification. AC: default CI succeeds with no credential environment and no customer fixture downloads.

**TEST-GATE-002.** New schema fields require updated fixtures, negative validation and compatibility tests; new collector fields require sensitivity review. AC: schema additions do not silently widen old readers or export policies.

**TEST-PERF-001.** Generate synthetic large fixtures deterministically; measure heap, parse/validation time and responsiveness against PRD-009. AC: results include dataset size, machine/runtime and p50/p95 timings; release budgets adjusted only with documented stakeholder approval.
