## Status

Complete

## Owner

## Objective

Extend `@ghec/github-client` with a typed `GitHubActionsService` that provides an end-to-end interface for dispatching migration workflows, tracking matrix cohorts, streaming job progress, cancelling runs, and decompressing execution report artifacts in memory.

## Context & Compatibility with Recent CLI Advancements

Recent monorepo work introduced:

- Five new migration modules (Tasks 031–035): `releases`, `deploy-keys`, `collaborators`, `lfs`, `packages`.
- Dynamic matrix slicing (`ScopeMatrixSlicer` with `--split-matrix`) alongside single-runner topologies.
- Standardized execution artifacts (`cohort-report-*.json`, `migration-plan.json`, `verification-report.json`, `test-preflight-report.json`).

The `GitHubActionsService` must natively handle inputs for all 17 registered modules, parse matrix cohort jobs, and extract all execution report artifacts.

## Detailed Requirements

1. **Workflow Dispatch Wrappers**:
   - `dispatchWave(options: WaveDispatchOptions): Promise<{ runId: number }>`
     - Dispatches `migration-execute-wave.yml`.
     - Supports parameters: `scope`, `batch_size`, `modules` (supporting all 17 modules), `dry_run`, `continue_on_error`, `runner_labels`, `environment_gate`.
     - Solves the GitHub 204 No Content return by immediately locating the newly queued run ID via `GET /actions/workflows/{id}/runs?event=workflow_dispatch&created=>={dispatchTime}`.
   - `dispatchTestMigration(options: TestDispatchOptions): Promise<{ runId: number }>`
     - Dispatches `test-migration-dispatch.yml` with preflight check enabled.
   - `dispatchResumeWave(runId: number): Promise<{ runId: number }>`
     - Dispatches `migration-resume.yml` with `--resume latest`.

2. **Run & Job Telemetry Polling**:
   - `getRunStatus(runId: number, etag?: string): Promise<{ run: RunDetails, notModified: boolean, etag?: string }>`
     - Uses `If-None-Match` header to conserve rate limits.
   - `getRunJobs(runId: number): Promise<JobDetails[]>`
     - Parses dynamic matrix cohort jobs (`slicer`, `migrate-cohorts (cohort-1)`, `aggregate-and-verify`).
     - Extracts step names, step statuses (`queued`, `in_progress`, `completed`), step conclusions, and duration.

3. **Artifact Stream & Unpacker**:
   - `downloadAndUnpackArtifacts(runId: number): Promise<WaveRunArtifacts>`
     - Queries `GET /repos/{owner}/{repo}/actions/runs/{runId}/artifacts`.
     - Follows 302 redirect to storage blob URL, stripping `Authorization` header.
     - Streams ZIP archive into memory.
     - Parses contained JSON files into typed objects:
       - `migration-plan.json` -> `MigrationPlan`
       - `verification-report.json` -> `VerificationReport`
       - `cohort-report-*.json` -> `CohortExecutionReport[]`
       - `test-preflight-report.json` -> `PreflightReport`

## Acceptance Criteria

1. `GitHubActionsService` successfully dispatches workflows and resolves the run ID.
2. Job polling correctly identifies parallel cohorts generated by `ScopeMatrixSlicer`.
3. In-memory decompression parses JSON artifacts from valid ZIP buffers without writing temporary files to disk.
4. Unit tests in `packages/github-client/tests/actions-service.test.ts` pass with 100% mocked coverage.
