## About dependency review

You can use the REST API to view dependency changes, and the security impact of these changes, before you add them to your environment. You can view the diff of dependencies between two commits of a repository, including vulnerability data for any version updates with known vulnerabilities. For more information about dependency review, see [AUTOTITLE](/code-security/concepts/supply-chain-security/dependency-review).

## Get a diff of the dependencies between commits

`GET /repos/{owner}/{repo}/dependency-graph/compare/{basehead}`

Gets the diff of the dependency changes between two commits of a repository, based on the changes to the dependency manifests made in those commits.

### Parameters

| Name | In | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `owner` | path | `string` | Yes | The account owner of the repository. The name is not case sensitive. |
| `repo` | path | `string` | Yes | The name of the repository without the `.git` extension. The name is not case sensitive. |
| `basehead` | path | `string` | Yes | The base and head Git revisions to compare. The Git revisions will be resolved to commit SHAs. Named revisions will be resolved to their corresponding HEAD commits, and an appropriate merge base will be determined. This parameter expects the format `{base}...{head}`. |
| `name` | query | `string` | No | The full path, relative to the repository root, of the dependency manifest file. |

### HTTP Response Status Codes

| Status Code | Description |
| :--- | :--- |
| `200` | OK |
| `400` | Bad Request |
| `403` | Response for a private repository when GitHub Advanced Security is not enabled, or if used against a fork |
| `404` | Resource not found |
| `500` | Internal Error |
| `503` | Service unavailable |
