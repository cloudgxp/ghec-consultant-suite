# @ghec/dashboard — Offline Migration Assessment & Control Plane

`@ghec/dashboard` is a local web application built with Vite, React 19, and GitHub Primer that helps you review migration readiness and export assessment reports completely offline.

---

## Reviewing discovery bundles in your browser

By default, `@ghec/dashboard` runs locally on `http://localhost:5173` and analyzes discovery bundle JSON files directly in your browser without connecting to GitHub or using any tokens:

- **Works 100% offline**: Inspect `.json` discovery bundles locally without network calls or credentials.
- **Automatic readiness scoring**: Uses `@ghec/analysis` to flag repositories over 40 GiB, commits over 2 GiB, Git LFS files, and releases over 10 GiB.
- **Fast tables for large organizations**: Uses `@tanstack/react-virtual` to search, filter, and compare tens of thousands of repositories, teams, users, and secrets smoothly.
- **PDF and CSV report exports**: Generates client-ready PDF reports (`jspdf` and `jspdf-autotable`) and CSV spreadsheets directly from your browser.

To start the local development server from the repository root:

```bash
npm run dev
```

To start the development server directly inside the dashboard workspace:

```bash
npm run dev -w @ghec/dashboard
```

Once the server starts, open `http://localhost:5173` in your browser and upload a bundle generated by `ghec-consultant-cli discover` or a sample file from `fixtures/synthetic/`.

## Testing and building the dashboard

By default, the dashboard quality checks run offline to verify TypeScript types, bundle sizes, keyboard accessibility, and visual layout snapshots.

To check TypeScript types across the dashboard:

```bash
npm run typecheck -w @ghec/dashboard
```

To build the production bundle and check file size limits:

```bash
npm run build -w @ghec/dashboard
```

To run the Playwright browser interaction and accessibility tests:

```bash
npm run test:e2e -w @ghec/dashboard
```

To run the visual snapshot comparison tests:

```bash
npm run test:visual -w @ghec/dashboard
```

> [!NOTE]
> The dashboard never sends uploaded customer data outside your browser tab and does not require a GitHub account to view reports.
